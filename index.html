PROJECT OVERVIEW

About Wanderly AI

Personalized Travel Itinerary Planner

A travel planning web application concept that helps travelers organize personalized trips based on destination, budget, duration, interests and travel style.

Technology stack for the full project

Frontend: React

Backend: FastAPI (Python)

Database and authentication: Supabase

AI: Generative AI API with prompt engineering

This downloadable single-file demo uses HTML, CSS, JavaScript and browser local storage. It does not yet connect to React, FastAPI, Supabase or a real AI service.
